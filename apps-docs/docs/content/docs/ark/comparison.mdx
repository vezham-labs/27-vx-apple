The Arc column uses the [byearc feature matrix](https://byearc.com/compare/) as its reference, with date-sensitive changes from Arc's help center called out where relevant. The Ark columns reflect workspace code and documented checks as of November 25, 2026. iPhone, iPad, and iPhone Duo share the iOS app. Duo has its own column because its cover and inner displays use different layouts.

**Yes** means the feature is implemented. **Partial** means its scope or compatibility is limited. **No** means that platform lacks the feature. **Unverified** means the available evidence did not establish support. **—** means the feature does not apply.

Ark uses [WebKit](/docs/ark/engines) across platforms. The migration counts use byearc’s catalog for Arc and Ark’s local importer for its source count.

## Feature matrix

The review inventory now includes Browsa `46fe04be` and Search `b9fcbb45`. The November 26 Search pull added nine commits. The [commit inventory and remaining work](../../../../../vx/TODO/ark-upstream-review.md) records review dispositions and verification gaps. Arc remains the interaction reference for Ark’s own Mac sidebar.

The upstream review count is provisional until the remaining inventory entries are individually reconciled. The Mac matrix has 20/42 rows rated Yes (47.6%); build-only and unverified behavior do not count as runtime parity. The rebuilt Mac feature tour now completes after fixing a top-level JSON string exception in its pinned-link fixture. It verified Today and Glance destinations from a pinned page, return-to-previous-tab behavior, split layouts, pin-folder moves, profile isolation, Boost persistence, and Easels capture. The latest isolated profile run also verified that a Space profile rebuilds its page on the named store, retains a page when moved between same-profile Spaces, and clears session state before a cross-profile rebuild. A loopback-only dynamic feed run now verifies Live Folder discovery, changed refresh with stable article IDs, cached-data retention after a failed refresh, and imported-folder resume. The existing Debug snapshot tour verified waking a sleeping page at its prior inner scroll offset. An idle Debug-app CPU/RSS baseline is recorded; representative workload performance is still unmeasured. See the [sync log](../../../../../vx/TODO/ark-sync-log.md) for evidence and remaining checks.

A local Mac MV3 extension fixture verified pinned-tab creation, pin/unpin updates, a browser-originated pin-change event, private pin rejection with private access enabled, and active blank-tab navigation without creating a second tab. Broader extension compatibility still needs verification; Chrome extension compatibility remains Partial.

GitHub Pull Requests Live Folder requests restrict cookie-bearing redirects to HTTPS GitHub and cap responses at 2 MB. Per-Space organization filters are available from the folder menu and operate on cached items. Shared-model checks and a Mac fixture verified filtering; signed-in GitHub and menu interaction remain unverified.

A local Mac sync fixture also verified that a remote profile change replaces the existing WebView with one using the new profile, and that a pinned tab moved by sync between different-profile Spaces receives a new WebView. Physical-device sync and iOS runtime behavior remain unverified.

An isolated Mac Glance fixture verified that closing a preview, invoking its navigation-commit callback, or promoting a fully loaded preview cancels a queued screen-permission request. The promotion retained its live page. Real WebKit screen sharing remains unverified.

Mac can export all regular Spaces as an HTML bookmarks file, retaining pin folders and open links, with separate Favorites folders per profile. It excludes private, agent, non-web, and credentialed links. A local fixture verified sample folder structure, Default favorites, separation of two named profiles, escaping, and private-link filtering; the save dialog and importing into other browsers remain unverified. The single-Space JSON format remains available.

The Mac Boost picker shows an Option-hover related-element count. An isolated fixture posted hover and click events over three matching elements, verified the count, hide, and restore, and captured a [Mac preview](../../../../../preview/ark/mac/features/boost-related-count.png). Physical pointer and VoiceOver interaction remain unverified.

Mac Easel image cards have an annotation mode. An isolated fixture set strokes through the model and captured an [annotated card preview](../../../../../preview/ark/mac/features/easel-image-annotation.png); another fixture verified their appearance in an exported PNG, and a store fixture verified persistence and clearing across reloads. WebKit rendered the ZIP HTML with expected image-relative stroke bounds in an [export preview](../../../../../preview/ark/mac/features/easel-annotation-export.png). An isolated Mac audit posted a system drag that created a stroke and verified the Clear button; it also verified Undo separately. See the [drawn-stroke preview](../../../../../preview/ark/mac/features/easel-image-annotation-drawn.png). Physical pointer and VoiceOver interaction, broader cross-format alignment, and full-app relaunch remain unverified.

The newest fetched feature branches do not advance those pinned `main` heads. Search's many-tab
branch is retained as a future measurement reference, while its declarative-content branch records
a concrete Chrome-extension gap: Ark has no persisted declarative rule/injection bridge yet.
Google Meet mini-window experiments and Browsa's GitHub-organisation settings need their own
reproducing product paths, so they do not change a feature rating.
