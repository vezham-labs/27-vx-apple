The Arc column uses the [byearc feature matrix](https://byearc.com/compare/) as its reference, with date-sensitive changes from Arc's help center called out where relevant. The Ark columns reflect workspace code and documented checks as of November 24, 2026. iPhone, iPad, and iPhone Duo share the iOS app. Duo has its own column because its cover and inner displays use different layouts.

**Yes** means the feature is implemented. **Partial** means its scope or compatibility is limited. **No** means that platform lacks the feature. **Unverified** means the available evidence did not establish support. **—** means the feature does not apply.

Ark uses [WebKit](/docs/ark/engines) across platforms. The migration counts use byearc’s catalog for Arc and Ark’s local importer for its source count.

## Feature matrix

The incoming implementation review targets Browsa `e981df56` and Search `33ec7aea` (November 24, 2026). These heads are not yet fully synced. The [commit inventory and remaining work](../../../../../vx/TODO/ark-upstream-review.md) tracks each incoming change. Arc remains the UI/UX reference for the entire Mac sidebar; upstream interface designs are not automatically adopted. Existing ratings below remain tied to their recorded verification.

Upstream review progress is 28/263 commits (10.6%). The Mac matrix has 21/42 rows rated Yes (50%); build-only and unverified behavior do not count as runtime parity.
